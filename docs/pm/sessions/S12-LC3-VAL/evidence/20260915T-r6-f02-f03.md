  seam; its durable identity (volume `st_dev` + file index `st_ino` + size +
  mtime_ns) is recorded in the publication **intent before** the exclusive
  link (`staged_identity`), next to the attempt's own candidate identity.
- The exclusive create (`os.link`) can only expose that staged inode; the
  published file is verified against the staged identity before any
  companion write.
